# ARCHITECTURE_V3 - 36 meses

Actualizado: 2026-06-16

## Objetivo

Convertir ClasesDe10 en plataforma regional escalable con SEO programatico, matching avanzado y dashboards mantenibles por equipo.

## Stack candidato

- Astro o Next.js para frontend publico componentizado.
- Supabase o Postgres gestionado con API propia.
- Job queue para automatizaciones.
- Email transactional formal.
- Observabilidad: logs, errores, metricas negocio.

## Cambios clave

- Componentes compartidos.
- Generacion programatica de paginas SEO.
- Matching por scoring.
- Pagos integrados.
- CRM ligero interno.
- Perfiles publicos seleccionados.

## Criterio de entrada

Migrar solo si hay suficiente contenido/producto para justificar build step y equipo tecnico.
