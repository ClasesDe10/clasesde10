# BUSINESS_MODEL_REVIEW - ClasesDe10

Actualizado: 2026-06-16

## Escenarios comparados

| Modelo | Margen | Calidad | Escala | Riesgo |
|---|---:|---:|---:|---:|
| Curado con comision | Alto | Alta | Media | Operacion humana |
| Marketplace abierto | Medio | Variable | Alta | Confianza/fraude |
| Suscripcion familias | Alto | Media | Media | Churn si no hay uso |
| Pack prepago | Alto | Alta | Media | Gestion pagos/saldos |
| Profesor empleado | Control alto | Alta | Baja/media | Coste fijo |
| B2B colegios | Alto | Alta | Media | Venta lenta |
| Grupos reducidos | Alto | Media | Alta | Scheduling |

## Modelo recomendado 1 ano

Curado con comision o pack prepago. Mantener control de calidad y recoger datos.

## Modelo recomendado 3 anos

Curado + marketplace semi-controlado. Profesores verificados con ranking interno, disponibilidad y pipeline de leads.

## Modelo recomendado 5 anos

Plataforma multi-ciudad con:

- Oferta verificada.
- Matching automatizado.
- Pagos integrados.
- Reputacion y calidad.
- Contenido SEO nacional/local.

## Regla financiera

No automatizar lo que aun no tiene proceso operativo estable. Primero documentar el playbook humano; luego automatizar.
