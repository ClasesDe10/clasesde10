# ARCHITECTURE_V4 - 60 meses

Actualizado: 2026-06-16

## Objetivo

Plataforma nacional multi-ciudad con calidad controlada, data propia, automatizacion avanzada y soporte operacional.

## Stack candidato

- Frontend app: Next.js/Astro hibrido.
- Backend: Postgres gestionado con API de dominio.
- Jobs: cola gestionada.
- Search: Postgres search, Meilisearch, Typesense o Algolia segun escala.
- Data warehouse ligero para BI.
- Feature flags y experimentacion.

## Capacidades

- Ranking de profesores.
- Matching automatizado explicable.
- Pagos, facturas, wallets/saldos.
- SEO nacional/local.
- Calidad y reputacion.
- Atencion al cliente con trazabilidad.

## Riesgo

La complejidad debe ganarse. No construir V4 antes de que V2/V3 demuestren demanda y retencion.
